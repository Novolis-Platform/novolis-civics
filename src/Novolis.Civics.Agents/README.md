# Novolis.Civics.Agents

Heuristic actors that mutate <c>FiscalPolicy</c> only. They never invent legitimacy or settle stocks — <c>CivicEngine</c> does.

## Install

```bash
dotnet add package Novolis.Civics.Agents
```

**Prerequisites:** [.NET 10 SDK](https://dotnet.microsoft.com/download) (net10.0).
