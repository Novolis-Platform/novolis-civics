# Novolis.Civics.Simulation

Thin composition: advance one or more civic periods. Hosts supply <c>PeriodContext</c>; agents adjust policy elsewhere.

## Install

```bash
dotnet add package Novolis.Civics.Simulation
```

**Prerequisites:** [.NET 10 SDK](https://dotnet.microsoft.com/download) (net10.0).
